## What's new

- **Automatic updates.** From this version on, Crest installs new versions by itself, quietly, while you aren't using the island, then reopens and tells you it was updated. Turn it off in Settings > About if you'd rather choose. Updates still only install when the download matches GitHub's published checksum.
- **Music services you can switch on.** Settings > Music Apps now has switches for Spotify, Apple Music (the app, iTunes and music.apple.com) and YouTube, and you can still add any other app or website. The island names Apple Music and iTunes properly.
- **Fixed:** dragging the tab bubble could leave the island stuck open and ignoring clicks.

Updating from 1.0.2: install this one from Settings > About. Later updates install themselves.
